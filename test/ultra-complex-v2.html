텍스트, 표, 도형, 그라디언트는 편집 가능한 개체가 됩니다. 필터와 블렌드 모드, 배경 클립 텍스트는 그림으로 저장됩니다. 다단(column-count)은 단마다 텍스트 상자 하나로 나뉘므로, 본문은 가능하면 일반 흐름으로 쓰세요.

명령: 스크립트 경로는 프로젝트 기준 상대 경로입니다.

Summary

정리

구조

  • 단일 HTML · 외부 의존성 없음
  • section.slide 1280×720 고정 크기
  • 색은 :root 토큰으로 역할별 관리

데이터

  • 차트는 데이터 배열에서 SVG로 생성
  • 차트마다 표 뷰를 함께 배치
  • 툴팁은 보조 수단, 값은 표에서도 확인

변환

  • 텍스트·표·그라디언트 → 네이티브
  • SVG·캔버스 → 벡터 또는 2x 이미지
  • 필터·블렌드 모드 → 그림으로 저장
