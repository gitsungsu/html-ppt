# ppt-template-html 설명서

이 문서는 `ppt-template-html` 스킬을 처음 쓰는 사람을 위한 사용 설명서입니다. 명령과 검사 규칙의 짧은 목록은 `SKILL.md`에도 있습니다. 이 문서는 준비, 순서, 문법, 결과 해석, 문제 해결을 한곳에 정리합니다.

---

## 1. 이 스킬이 하는 일

샘플 PPTX의 **양식**(레이아웃, 글꼴, 글자색, 배경 그림, 로고, 장식)을 배우고, 그 양식에 맞춘 **HTML 슬라이드**(1280×720)를 만듭니다. 만든 HTML은 규칙으로 검증하고, 원본 PowerPoint 레이아웃과 나란히 비교할 수 있습니다.

```
샘플 PPTX (1개 이상, 권장 2개 이상)
   │  extract-template.mjs
   ▼
template-spec.json + assets/        ← 양식 정보의 유일한 기준
   │
   ├─ spec-to-master.py ───────────► 슬라이드 마스터 PPTX (선택)
   │
content.md + 그림 + CSV/XLSX
   │  build-deck.mjs
   ▼
deck.html (1280×720 슬라이드)
   │  check-deck.mjs              → 검사 리포트 (report.json)
   │  compare.mjs (PowerPoint)    → 원본과 레이아웃별 비교 (report.md)
   │  html-ppt/build_pptx.mjs     → 편집 가능한 PPTX (선택)
```

- 스킬 본체(`scripts/`의 .mjs, .py)는 HTML을 만듭니다.
- PPTX 파일은 마스터(`spec-to-master.py`)와 `html-ppt` 스킬의 `build_pptx.mjs`를 이어서 만듭니다.
- 차트, 애니메이션, 그룹, SmartArt는 다루지 않습니다.

## 2. 준비

| 항목 | 필요한 곳 | 없을 때 |
|---|---|---|
| Node.js 18 이상 | 모든 `.mjs` | 실행 불가 |
| npm 설치 | `scripts/`에서 `npm install` (jszip, playwright) | XLSX 읽기, 검사, 비교 불가 |
| Chromium | `npx playwright install chromium` | `check-deck`, `compare` 불가 |
| Python 3 + python-pptx 1.0.2 + lxml | `spec-to-master.py` | 마스터 PPTX 생성 불가 |
| pdfplumber 0.11.10 | `pdf-to-pptx.py` (PDF 샘플만 있을 때) | PDF 재구성 불가 |
| Windows + PowerPoint | `compare.mjs`, `make-layout-slides.ps1`, `render_pptx.ps1`, 테스트 fixture | 비교는 종료 코드 4로 건너뜀 |
| html-ppt의 npm 설치 | `.claude/skills/html-ppt/scripts`에서 `npm install` | PPTX 내보내기 불가 |
| 샘플의 글꼴 | 예: 나눔고딕 | 대체 글꼴로 보임 |

설치 명령:

```bash
cd .claude/skills/ppt-template-html/scripts && npm install && npx playwright install chromium
cd ../../html-ppt/scripts && npm install
```

**작업 환경 메모**

- 명령은 프로젝트 루트에서 Git Bash로 실행합니다. `.ps1` 파일만 PowerShell에서 실행합니다.
- 콘솔이 cp949라서 Python이 한글을 출력하지 못하면 `PYTHONIOENCODING=utf-8`을 앞에 붙입니다.
- 명령 예에서 `$SKILL`은 `.claude/skills/ppt-template-html`을 뜻합니다.

## 3. 빠른 시작 (단계별)

### 3.1 양식 학습

```bash
node $SKILL/scripts/extract-template.mjs <샘플1.pptx> [샘플2.pptx ...] --out <템플릿폴더> [--primary <샘플.pptx>]
```

- **샘플 여러 개**: 각 값을 다수결로 정합니다. 동점이면 `--primary`로 지정한 샘플의 값을 쓰고, 종료 코드 3을 냅니다. 결과 파일은 그대로 만들어집니다. `--primary`를 생략하면 파일 이름 순서의 첫 파일이 기준입니다. `--primary`는 샘플 중 하나여야 합니다.
- **샘플 1개**: 값을 그대로 씁니다. `warnings`에 `single sample: values taken as-is, no majority vote`가 기록되며, 이것은 정상입니다.
- **출력**: `<템플릿폴더>/template-spec.json`, `<템플릿폴더>/assets/`. `assets/`는 실행할 때마다 지우고 새로 만듭니다.
- **PDF만 있을 때**: 원본 PPTX가 없으면 `python $SKILL/scripts/pdf-to-pptx.py <deck.pdf> <출력폴더>`로 근사 PPTX를 만들고, 그 파일을 샘플로 씁니다. 원본 마스터가 아니므로 결과는 근사치입니다.

### 3.2 콘텐츠 작성

`content.md` (또는 `content.txt`, 같은 규칙)를 씁니다. 문법은 [4장](#4-contentmd-문법)에 있습니다. 예:

```markdown
<!-- layout: Title Only -->
# **2025 기업가치 제고**~~(Value-up)~~ **이행 현황**
2025. 11

---

<!-- layout: Title and Content -->
# 주요 지표 현황
2025년 3분기 기준 주요 지표를 정리했습니다.
- 2024년 11월 발표 이후 중장기 기업가치 제고 계획을 이행 중
- 재무 건전성과 주주환원을 균형 있게 추진
[table: data.csv]
```

### 3.3 HTML 만들기

```bash
node $SKILL/scripts/build-deck.mjs <템플릿폴더>/template-spec.json <content.md> \
  --assets <그림폴더> [--data <데이터.csv 또는 .xlsx>]... --out <출력폴더> [--no-chrome]
```

- **결과**: `<출력폴더>/deck.html`, `<출력폴더>/assets/`, `<출력폴더>/build-report.json`
- **`--assets`**: `![](파일.png)`과 로고 등 그림을 찾는 폴더입니다. 없는 파일이 있으면 오류(종료 코드 2)입니다.
- **`--data`**: `[table: 파일명]`에 쓰는 데이터 파일입니다. 여러 번 줄 수 있습니다. 없으면 오류입니다.
- **`--no-chrome`**: 레이아웃 장식(로고, 배경 그림 등)을 HTML에 넣지 않습니다. PPTX로 내보낼 때 씁니다. 장식은 마스터 레이아웃이 가지고 있기 때문입니다.
- **경고**: `build-report.json`의 `warnings`에 적힙니다. 예를 들어 레이아웃 이름이 없어서 자동으로 골랐거나, 본문이 상자에 다 들어가지 않을 수 있을 때입니다. 경고만으로는 종료 코드가 바뀌지 않습니다.

### 3.4 검사

```bash
node $SKILL/scripts/check-deck.mjs <deck.html> <결과폴더> [--slides N] [--text-size warn|fail]
```

- **`--slides N`**: 기대하는 슬라이드 수입니다.
- **`--text-size warn`**: 원본 글자 크기가 16px보다 작을 때, 그 글자를 실패가 아닌 경고(`warn`)로 봅니다. 원본 크기를 그대로 살리려면 이 옵션을 씁니다. 기본값은 `fail`입니다.
- **출력**: 표준 출력에는 문제가 있는 줄만 나옵니다. 한 줄의 형식은 다음과 같습니다.

  ```
  <종류> | slide <n> | <규칙> | <결과> | <선택자> | "<발췌>"
  ```

  - 종류: `content`(내용, 개수에 셈) 또는 `chrome`(장식, 보고만 함)
  - 결과: `fail`, `warn`, `human-check`(사람이 확인), `reported`
  - 슬라이드 0은 덱 전체를 뜻합니다. 선택자 번호는 0부터 셉니다.
- **파일**: `<결과폴더>/report.json`(모든 결과와 스크린샷 목록)
- **종료 코드**: 0은 내용 실패 없음, 1은 내용 실패 있음, 2는 입력 오류입니다.

**검사 규칙 요약**

| 규칙 | 기준 |
|---|---|
| `canvas` | 16:9, 1280×720 |
| `contrast` | 글자와 바탕의 대비 4.5:1 이상 (바탕은 실제로 그려진 요소로 정함) |
| `safe-area` | 바깥 5% 안에 있어야 함 (좌우 64px, 상하 36px) |
| `overlap` | 상자끼리 겹침이 20%를 넘으면 실패 |
| `text-size` | 글자 16px 이상 (`--text-size`로 경고 처리 가능) |
| `overflow`, `clipped` | 글자가 상자 밖으로 넘치거나 잘림 |
| `colour` | 읽을 수 없는 색(oklch 등). 색은 hex만 씁니다. |
| `slide-count` | `--slides`와 다름 |
| `console`, `page-error`, `request-failed`, `http` | 브라우저 오류 |

그 밖의 규칙(`mermaid`, `presenter` 등)은 원본 `ppt-style-html`의 검사기에서 가져왔습니다.

**사람이 확인할 항목**: 그림 위의 글자, 그라데이션과 투명 배경, 그림 배경 레이아웃은 자동으로 판정하지 않고 `human-check`로 표시합니다.

### 3.5 원본과 비교 (PowerPoint 필요)

```bash
node $SKILL/scripts/compare.mjs --spec <template-spec.json> --sample <샘플.pptx> \
  --filler $SKILL/fixtures/filler.md --out <결과폴더>
```

- 이 명령이 PowerPoint로 원본 레이아웃을 그리고(`make-layout-slides.ps1`), 같은 레이아웃을 HTML로 만들어 비교합니다. 보통은 `compare.mjs`만 실행합니다.
- **판정 기준**
  - 색: 많이 쓴 색 8개의 ΔE76 평균이 15 이하이면 통과, 12~18이면 사람 확인
  - 구조: 상자 쌍의 IoU 평균이 0.8 이상이면 통과, 0.6~0.8이면 사람 확인
  - 그림 배경 레이아웃은 항상 사람 확인
- **파일**: `report.md`(사람이 읽는 보고서), `report.json`, `original/`, `original-lb/`(1280×720 letterbox), `generated-png/`
- **종료 코드**: 0은 실행 완료(판정은 보고서에 있음), 2는 입력 오류, 4는 PowerPoint가 없어서 비교를 건너뜀입니다.

### 3.6 PPTX로 내보내기 (편집 가능한 파일)

이 스킬은 HTML을 만들고, PPTX는 두 도구로 이어서 만듭니다.

**① 슬라이드 마스터 만들기** (양식을 PowerPoint 마스터로)

```bash
PYTHONIOENCODING=utf-8 python $SKILL/scripts/spec-to-master.py \
  <템플릿폴더>/template-spec.json <템플릿폴더>/assets <출력폴더>/skhynix-master.pptx
```

테마 색과 글꼴, 레이아웃(장식, 제목·본문·부제 자리표시자의 위치와 글자 스타일)을 만듭니다.

**② 장식 없는 HTML 만들기**

```bash
node $SKILL/scripts/build-deck.mjs <템플릿폴더>/template-spec.json <content.md> \
  --assets <그림폴더> --data <데이터.csv> --out <HTML폴더> --no-chrome
```

**③ PPTX 만들기**

```bash
node .claude/skills/html-ppt/scripts/build_pptx.mjs <HTML폴더>/deck.html <출력.pptx> \
  --template <출력폴더>/skhynix-master.pptx
```

- 제목은 마스터의 제목 자리표시자, 본문은 본문 자리표시자, 부제(본문 첫 줄, 글머리 없음)는 부제 자리표시자에 들어갑니다. 레이아웃에 자리표시자가 없으면 글상자로 대신합니다.
- 실행 결과에 `fonts used (must be installed ...)`로 나온 글꼴은 PPTX를 여는 PC에 설치되어 있어야 원래 모양으로 보입니다.

**④ 확인** (PowerPoint 필요)

```powershell
powershell -File .claude/skills/html-ppt/scripts/render_pptx.ps1 <출력.pptx> <PNG폴더>
```

## 4. content.md 문법

| 문법 | 뜻 | 예 |
|---|---|---|
| `---` (한 줄) | 슬라이드 구분 | |
| `<!-- layout: 이름 -->` (슬라이드 첫 줄) | 쓸 레이아웃. 대소문자는 구분하지 않음. 없으면 경고 후 자동 선택 | `<!-- layout: Title Only -->` |
| `# 제목` | 슬라이드의 첫 `#`은 제목 | `# 주요 지표 현황` |
| `# 다른 줄` (제목 뒤) | 본문 항목으로 씀 | |
| `- 항목` 또는 `* 항목` | 글머리 기호 항목 | `- 매출 증가` |
| `1. 항목` | 번호 항목 (글머리 기호 아님) | `1. 첫째` |
| 그냥 쓴 줄 | 본문 줄. 부제 자리가 있는 레이아웃에서는 첫 번째 일반 줄이 부제가 됨 | `2025. 11` |
| `![](파일.png)` | 그림. `--assets` 폴더에서 찾음 | `![](logo.png)` |
| `[table: 파일.csv]` | 표. `--data`로 넘긴 CSV 또는 XLSX 첫 시트 | `[table: data.csv]` |
| `**굵게**` | 굵은 글씨 | `**2025 이행 현황**` |
| `~~가늘게~~` | 굵기 400 (굵은 제목 안에서 일부를 가늘게 할 때) | `**제목**~~(부제)~~` |

**규칙**

- `**`와 `~~`는 한 줄 안에서만 적용됩니다. 중첩할 수 없고, 짝이 맞아야 합니다.
- 표 셀 안에서는 `**`와 `~~`를 읽지 않습니다.
- 슬라이드에 표가 있으면 종류가 `table`인 레이아웃을, 없으면 종류가 `content`인 레이아웃을 고릅니다. 레이아웃 이름을 적으면 그 레이아웃을 씁니다.
- 샘플에 없는 레이아웃 이름(예: `Section Header`)을 적으면 경고가 나오고, 자동으로 다른 레이아웃을 씁니다.

## 5. 명령과 종료 코드

| 명령 | 주요 옵션 | 종료 코드 |
|---|---|---|
| `extract-template.mjs` | `--out`(필수), `--primary` | 0 정상, 2 입력 오류, 3 동점(결과는 생성됨), 1 예기치 않은 오류 |
| `build-deck.mjs` | `--assets`, `--data`(반복 가능), `--out`(필수), `--no-chrome` | 0 정상(경고 있어도 0), 2 입력 오류, 1 예기치 않은 오류 |
| `check-deck.mjs` | `--slides N`, `--text-size warn\|fail` | 0 내용 실패 없음, 1 내용 실패 있음, 2 입력 오류 |
| `compare.mjs` | `--spec`, `--sample`, `--filler`, `--out` | 0 실행 완료, 2 입력 오류, 4 PowerPoint 없음 |
| `spec-to-master.py` | 인자 3개: spec, assets 폴더, 출력 PPTX | 0 정상, 그 밖에는 오류 |
| `pdf-to-pptx.py` | 인자 2개: PDF, 출력 폴더 | 0 정상, 그 밖에는 오류 |

**입력 제한**: PPTX와 XLSX는 50MB 이하, 2000개 항목 이하, 압축 해제 후 200MB 이하여야 합니다. 넘으면 종료 코드 2입니다.

## 6. 결과 파일 읽는 법

**`template-spec.json`** (양식 정보, 모든 단계의 기준)

| 키 | 내용 |
|---|---|
| `slideSize` | 샘플의 슬라이드 크기(EMU). 16:9 샘플이면 12192000×6858000 |
| `palette` | 테마 색 12개(hex) |
| `fonts` | 테마 글꼴(major, minor) |
| `observed` | 슬라이드에서 배운 값: `fonts`, `colours`(제목, 본문, 강조, 표 머리글), `layoutStyles`(레이아웃별 제목·본문·부제·본문 상자), `slides`(레이아웃별 슬라이드 수), `notes`(뺀 그림 등 기록) |
| `layouts[]` | 레이아웃 이름, 종류, 배경, 장식 목록, 자리표시자(위치와 글자 스타일) |
| `assets[]` | `assets/`에 있는 그림과 원본 파일 안의 위치 |
| `conflicts[]` | 동점으로 `--primary`를 쓴 항목 |
| `warnings[]` | 예: 샘플이 1개일 때 |

**`deck.html`**: 슬라이드마다 `section.slide`(1280×720)가 있고, 가운데 `.frame` 안에 내용이 있습니다. 장식은 `data-tpl="chrome"`, 제목·본문·부제는 `data-ph`와 `data-role`로 표시됩니다.

**`build-report.json`**: 빌드 경고 목록과 사용한 그림 목록입니다.

**`report.json`(검사)**: 모든 결과, 종류(content/chrome), 스크린샷 경로입니다.

**`report.md`(비교)**: 레이아웃마다 색 점수, 구조 점수, 판정(통과, 사람 확인, 실패)이 적힙니다.

## 7. 양식을 배우는 규칙

- **배경과 장식**: 레이아웃 XML의 그림과 마스터의 로고가 장식이 됩니다. 두 가지 경우는 장식에서 뺍니다.
  1. 그 레이아웃을 쓰는 슬라이드가 같은 위치와 크기에 같은 그림을 넣은 경우(슬라이드 내용의 복사본). 예: 목차 슬라이드의 번호 그림.
  2. 뒤에 있는 불투명 전면 그림(JPEG)에 완전히 가려지는 경우.
  - 빠진 그림은 `notes`에 기록됩니다.
  - 60% 이상의 슬라이드에 반복되는 그림은 장식으로 추가합니다. 90% 이상을 덮으면 배경 그림이 됩니다.
- **글꼴과 글자색**: 글자 수 가중 최빈값입니다. 제목은 제목 자리표시자의 글자, 나머지는 본문의 글자로 셉니다. 글꼴 이름의 굵기 단어(ExtraBold 등)는 뺍니다.
- **레이아웃별 제목·본문·부제·본문 상자**: 위치는 중앙값, 나머지 속성은 최빈값입니다.
- **우선순위** (제목과 본문의 위치, 크기, 색, 굵기, 정렬): 레이아웃별 학습값 > 자리표시자 글자 스타일 > 전체 `observed` > 기본값. 값이 `null`이면 다음 단계로 넘어갑니다.
- **안전 영역**: 학습한 상자가 바깥 5%에 걸치면 빌드할 때 안으로 옮깁니다. `template-spec.json`의 값은 그대로 둡니다.

## 8. 문제 해결

| 증상 | 원인과 해결 |
|---|---|
| `layout "X" not found in the spec` | 레이아웃 이름이 다릅니다. `template-spec.json`의 `layouts[].name`을 확인하세요. |
| `image not found in --assets: X` | 파일 이름, 확장자, 폴더를 확인하세요. 대소문자 차이는 허용됩니다. |
| `data file not given for [table: X]` | `--data`에 그 파일을 넘기세요. |
| `unused data file` 경고 | `content.md`에서 쓰지 않은 데이터 파일입니다. 무시해도 됩니다. |
| 글자 크기 실패 (`text-size`) | 원본 본문이 16px보다 작을 수 있습니다. 원본 크기를 살리려면 `--text-size warn`을 쓰세요. |
| 대비 실패 (빨간 글자 등) | 원본 색을 그대로 쓴 경우입니다. 실패를 고치기보다 `human-check`로 확인하세요. |
| `compare` 종료 코드 4 | PowerPoint가 없습니다. Windows에서 PowerPoint를 설치하고 다시 실행하세요. |
| 한글이 깨져서 출력됨 | `PYTHONIOENCODING=utf-8`을 붙이세요. |
| PPTX에서 글꼴이 다르게 보임 | `must be installed` 목록의 글꼴을 PPTX를 여는 PC에 설치하세요. |
| 마스터에 원치 않는 그림이 보임 | 샘플 슬라이드의 복사본일 수 있습니다. [7장](#7-양식을-배우는-규칙)의 규칙으로 빠졌는지 `notes`에서 확인하세요. |
| 파일 저장이 안 됨 (`~$파일명` 잠금 파일) | PowerPoint에서 그 파일을 닫고 다시 실행하세요. |

## 9. 알려진 한계

- 날짜는 원래 값으로 나옵니다. 엑셀 서식은 백분율, 통화, 천 단위 구분만 적용하고, XLSX는 첫 시트만 읽습니다.
- 그룹, SmartArt, 애니메이션은 읽지 않습니다. EMF와 WMF 그림은 그리지 않고 `warnings`에만 적습니다(테스트 데이터가 없어 검증하지 않음).
- 그림 배경 위의 글자 대비는 사람이 확인합니다.
- `::before`, `::after` 배경은 측정하지 않습니다. 샘플 점 간격보다 얇은 띠는 놓칠 수 있습니다.
- `deck.html`과 `assets/`는 함께 옮겨야 그림이 보입니다.
- 16:9가 아닌 샘플은 가운데에 두고 양옆을 흰색으로 채웁니다.
- 비교는 제목과 본문 자리만 채웁니다. 날짜, 바닥글, 쪽 번호, 그림 자리는 빈 채로 둡니다.
- 샘플에 없는 레이아웃(예: 간지 `Section Header`)은 다른 레이아웃으로 대체됩니다.
- PDF로 만든 샘플은 원본 마스터가 아니므로 근사치입니다.
- 마스터는 샘플의 레이아웃 구조를 그대로 따르므로, 레이아웃 수와 이름은 샘플에 따라 달라집니다.

## 10. 이 프로젝트에서 실제로 쓴 예

원본 `skhynix_ppt_templet.pptx`(12쪽, 디자인이 슬라이드에 있는 샘플)로 만든 경우입니다. 프로젝트 루트에서 실행합니다.

```bash
# 1) 양식 학습 (샘플 1개 → 단일 샘플 모드)
node .claude/skills/ppt-template-html/scripts/extract-template.mjs skhynix_ppt_templet.pptx --out templates/skhynix-pptx

# 2) 슬라이드 마스터 생성
PYTHONIOENCODING=utf-8 python .claude/skills/ppt-template-html/scripts/spec-to-master.py \
  templates/skhynix-pptx/template-spec.json templates/skhynix-pptx/assets templates/skhynix-pptx/skhynix-master.pptx

# 3) 장식 없는 HTML 생성 (내용: templates/skhynix-src/content.md, 표: data.csv)
node .claude/skills/ppt-template-html/scripts/build-deck.mjs templates/skhynix-pptx/template-spec.json \
  templates/skhynix-src/content.md --assets templates/skhynix-pptx/assets \
  --data templates/skhynix-src/data.csv --out out/skhynix-pptx-nochrome --no-chrome

# 4) PPTX 생성 (마스터 사용)
node .claude/skills/html-ppt/scripts/build_pptx.mjs out/skhynix-pptx-nochrome/deck.html \
  out/skhynix-pptx/final-clean.pptx --template templates/skhynix-pptx/skhynix-master.pptx
```

**이때 확인한 것**

- 표지 제목은 한 제목 자리표시자 안에 굵은 글자와 가는 글자가 섞인 채 들어갔습니다.
- 3쪽 본문, 부제, 표는 제 위치에 나왔습니다.
- 마스터의 목차 번호 그림은 제거했습니다(7장 규칙).

추출기 회귀 확인(샘플 두 개가 같으면 0, 색이 다르면 동점 3, 0개면 2):

```bash
node $SKILL/scripts/extract-template.mjs $SKILL/fixtures/standard-office.pptx $SKILL/fixtures/standard-office-copy.pptx --out <폴더>   # 0
node $SKILL/scripts/extract-template.mjs $SKILL/fixtures/standard-office.pptx $SKILL/fixtures/standard-office-accent.pptx --out <폴더>  # 3

```

- `make-standard-office.ps1`은 테스트용 PowerPoint 샘플을 만듭니다. 실행 후 `make-fixtures.mjs`로 복사본을 다시 만듭니다.
- `check-deck.mjs`는 `ppt-style-html`의 `check-starter.mjs`를 복사한 것입니다. 원본의 SHA-256은 `7170353eaccef8f14c36afcac9cc332cbf47c18788ea37b2bf5b01290ebb576d`입니다. 원본과 다른 점 세 가지는 `SKILL.md`에 있습니다.
